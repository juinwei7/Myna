# Spec 002 — 驗收標準

執行方式：

```bash
cd mac
swift test                 # A：純邏輯（另有 LiveModelTests，指定測試服務的連接埠才跑，見檔頭）
make app                   # B：打包與簽章
scripts/acceptance.sh      # C：生命週期（起 app、查服務、結束後不留程序）
```

D、E 是介面項目，用截圖存證並逐條對照（憲法 C3）。

---

## A — 純邏輯（`swift test`）

| # | 檢查 | 通過條件 |
|---|---|---|
| A1 | 可用模型 | 只列已下載且支援該方式的模型；配音員再依模型有沒有這位過濾 |
| A2 | 預設選擇 | 沒選過時用該方式的預設模型；預設的沒下載就退到第一個可用的 |
| A3 | 不能產生的原因 | 沒稿子、沒模型、沒聲音、描述沒寫，各有對應的中文原因 |
| A4 | 語氣欄 | 只有模型宣告支援該方式的語氣時才顯示；描述方式一律顯示 |
| A5 | 比較 | 比較清單只留仍可用的模型；少於兩個時視同關閉 |
| A6 | 顯示文字 | 大小（GB／MB）、長度（秒／分秒）、進度百分比格式正確 |
| A7 | 波形 | 任意長度的取樣點縮成指定格數，峰值正規化到 0～1；空輸入不當掉 |
| A8 | 工作追蹤 | 只回報「上次還在進行、這次已完成」的工作，不重複回報 |
| A10 | 最近的稿子 | 同一份稿子只列一次，用最新的版本代表並帶版本數；順序照各自最新的那一次 |
| A9 | 型別解碼 | 後端實際回傳的 JSON 樣本（模型、工作、紀錄、聲音、設定）都能解碼 |

## B — 打包

| # | 檢查 | 通過條件 |
|---|---|---|
| B1 | `make app` | 產出 `build/九官鳥.app`，簽章驗證通過 |
| B2 | 內附後端 | 內附的 Python 能 `import studio.app`；不含測試檔 |
| B3 | 名稱與圖示 | `CFBundleName` 是「九官鳥」；圖示檔是新圖示 |
| B4 | 服務選單宣告 | `Info.plist` 含 `NSServices`，接受純文字 |

## C — 生命週期

| # | 檢查 | 通過條件 |
|---|---|---|
| C1 | 啟動 | 打開 app 後 60 秒內 `/api/health` 回 200 |
| C2 | 模型清單 | `/api/models` 回 8 個模型 |
| C2 | 只留 app 與 MCP | 根路徑沒有網頁（404）；`/mcp` 的工具清單含 `synthesize`、`list_models` |
| C3 | 結束 | 結束 app 後，內附的後端程序不殘留 |
| C4 | 沿用 | 連接埠上已有服務時不另開第二份 |
| C5 | 強制結束 | app 被 `kill -9` 後，後端 10 秒內自己結束 |

## D — 介面（截圖）

| # | 檢查 | 通過條件 |
|---|---|---|
| D1 | 產生頁 | 單色側欄（搜尋、四區、最近產出、底部狀態）、工具列中間的方式切換、稿子、檢閱器、播放列都在；深色與淺色都正常 |
| D2 | 產生 | 送出後「這份稿子的版本」出現進度與階段文字；完成後變成一個版本 |
| D3 | 比較 | 同一批的版本排在一起並標示模型名稱；音檔詳情列出這份稿子的所有版本，可逐一試聽 |
| D4 | 音檔 | 表格五欄、可搜尋 |
| D5 | 聲音庫 | 清單＋文件樣式的詳情（宋體名稱、基本資料、文字樣式的動作、逐字稿） |
| D6 | 模型 | 分成已下載／可下載；顯示能力、大小、授權；不可商用有標示 |
| D7 | 設定 | 可拉大的視窗；側欄六頁分三組、彩色圖示、可搜尋、記得上次的頁面；每頁工具列最右邊的齒輪與 ⌘, 都打得開 |
| D8 | 沒有模型 | 產生頁列出推薦的模型讓使用者自己挑，各有下載鈕；不是錯誤、也不是只推一個 |

## E — macOS 準則檢查表

| # | 檢查 | 通過條件 |
|---|---|---|
| E1 | 選單列 | 每個動作都在選單裡，且有快捷鍵；不適用時停用 |
| E2 | 視窗 | 可自由縮放、有最小尺寸、記得大小 |
| E3 | 側欄 | 可收合、單色（圖示與選取不吃強調色）、列是按鈕且有選取狀態供旁白讀出 |
| E4 | 鍵盤 | ⌘↩ 產生、空白鍵播放、Delete 刪除、⌘Z 復原、⌘1～4 切換 |
| E5 | 滑鼠 | 右鍵選單、拖出音檔、拖入文字檔 |
| E6 | 視覺 | 色碼只出現在 `Theme.swift` 與圖示腳本；`grep` 其他檔案找不到色碼與 `.orange`／`accentColor` |
| E7 | 輔助使用 | 只有圖示的按鈕都有說明文字 |
