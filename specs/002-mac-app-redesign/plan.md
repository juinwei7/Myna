## 1. 版面

```
┌──────────────┬────────────────────────────────────┬─────────────────┐
│ 🔍 搜尋所有音檔 │        [ 仿聲 | 配音員 | 聲音描述 ]   ▶ 產生音檔 ▢ │
│              ├────────────────────────────────────┼─────────────────┤
│ 產生          │ 稿子（15 pt、行距寬，像一份文件）       │ 聲音 [台灣女聲▾] ▶│
│ 音檔      13  │                                    │ 模型 [VoxCPM2 ▾] │
│ 聲音庫     1  │                                    │   說明・授權      │
│ 模型       8  │                         78 字 約 17 秒│ 語氣             │
│              │ ────────────────────────────────── │ 語速 ──●── 1.00× │
│ 最近產出      │ 這份稿子的版本（宋體）                 │ ☐ 比較模型        │
│  這份稿子的開頭… │  ◐ OmniVoice 產生中 2／5 段      ✕   │ [   產生音檔   ]  │
│  10:26 VoxCPM2│  ▶ VoxCPM2  台灣女聲 10:27   2.2 秒 ⓘ │                 │
│  …           │  ▶ Breeze-TTS 2 …                   │                 │
│ ──────────── ├────────────────────────────────────┴─────────────────┤
│ ● 已就緒  匯入 │ ▶ 標題  0:03 ▁▃▅▇▅▃▁▃▅▇▅▃▁ 0:39  1×▾                   │
└──────────────┴──────────────────────────────────────────────────────┘
```

- **側欄是單色的**：頂端搜尋欄、四個導覽列（圖示與選取都是灰階，不吃強調色）、下面直接列「最近的稿子」
  （同一份稿子試了幾個版本都只列一次，標示版本數，點進去看得到全部）、
  底部固定一列（服務狀態、進行中的工作、匯入）。側欄自己排，不用系統的側欄清單（憲法 U7；系統清單也蓋不掉強調色）。
- **切換內容的分段控制放工具列中間**：「產生」頁是方式（仿聲｜配音員｜聲音描述），側欄只當導覽。
- **主色是柿橘、提示是琥珀**（憲法 U2）：主要按鈕、文字樣式的動作、播放中、波形已播放的部分用柿橘；
  不可商用、錄音太短這類提醒用琥珀色的提示條。
- **內容頁像一份文件**：宋體大標題 → 一行基本資料（次要色）→ 文字樣式的動作 → 分隔線 → 宋體段落標題與內文。
  音檔詳情、聲音詳情、模型清單的模型名稱都照這個讀法。
- **這份稿子的版本**：稿子下方列出跟目前稿子一字不差的產出與進行中的工作。
  同一份稿子換模型、換聲音試出來的版本自然排在一起，是比較的主要畫面；稿子一改，這一區就清空（舊的都在「音檔」）。
- **音檔詳情**：從側欄的最近的稿子、表格按兩下、或版本列的 ⓘ 進去。這份稿子的所有版本列在「這份稿子的版本」，可以逐一試聽、切換。
- **播放列**固定在視窗底部，四區共用：播放、目前時間、波形（可點按與拖曳跳轉）、總長、試聽倍速。
- 右側「聲音與模型」用系統的 `.inspector`，可以收起來專心寫稿（⌥⌘I）。
- **整頁只有一個主要按鈕**：工具列的「產生音檔」（主色）。還不能產生時，稿子下方那一行直接說缺什麼。
- **工具列最右邊是齒輪**，每一頁都有，打開設定（同 ⌘,）。
- 「音檔」用 `Table`：稿子、聲音、模型、長度、時間五欄，可排序、多選；搜尋走側欄的搜尋欄（⌘F）。

## 2. 互動規則

| 情境 | 行為 |
|---|---|
| 產生 | ⌘↩；做完自動播放（比較時只播第一筆） |
| 取消 | 進行中的列有取消鈕；⌘. 取消全部進行中的工作 |
| 播放 | 版本列按一下播放；表格裡空白鍵播放／暫停、按兩下看詳情 |
| 刪除 | Delete 鍵 → 進垃圾桶 → ⌘Z 可復原（憲法 U1） |
| 拖放 | 音檔可拖出（版本列、側欄、表格、播放列標題）；`.txt` 拖進稿子；音檔拖進聲音庫＝新增聲音 |
| 右鍵 | 每個音檔都有：播放、顯示詳情、用這份稿子、存成聲音、在 Finder 顯示、拷貝路徑、分享、丟到垃圾桶 |
| 回饋 | 例行動作用行內狀態；只有「刪除模型檔案」用確認對話框（憲法 U3） |
| 缺模型 | 選到的方式沒有已下載的模型時，檢閱器直接顯示「前往下載」 |
| 提醒 | 選到不可商用的模型時，稿子上方出現琥珀色提示條 |

## 2.1 設定視窗

設定是一般視窗（可以拉大），不是系統內建那種固定大小的分頁：

- 左邊側欄：頂端「搜尋設定」（比對頁名與那一頁項目的說法，只剩一頁就直接跳過去）、分組的頁面清單，
  每頁一個彩色圓角方塊加白色符號的圖示，選到的是灰底；記得上次停在哪一頁。
- 右邊是那一頁的分組表單。

| 分組 | 頁面 | 內容 |
|---|---|---|
| 內容 | 產生 | 三種方式的預設模型；產生完成後要不要自動播放、在背景時 Dock 圖示要不要跳 |
| | 發音字典 | 表格編輯；有沒儲存的變更會提示，儲存鈕才亮 |
| 資源 | 模型與記憶體 | 記憶體上限、目前載入了什麼；已下載幾個、佔多少、模型資料夾、打開「模型」 |
| 系統 | 一般 | 登入時自動打開；資料夾；資料都留在本機的說明 |
| | AI 工具 | MCP 位址（可拷貝）、能不能連、AI 工具能做的六件事 |
| | 檢查與狀態 | 語音服務、模型、ffmpeg 三項檢查（打勾或琥珀色提醒）；紀錄檔、重新啟動、版本 |

## 3. 模組

`VoiceStudioCore`（library，可測試）＋`VoiceStudio`（執行檔，只呼叫進入點）
＋`VoiceStudioCoreTests`。**為什麼**：執行檔 target 不能被 `@testable import`。

| 檔案 | 職責 |
|---|---|
| `APITypes.swift` | 後端 JSON 對應的型別 |
| `StudioClient.swift` | REST 呼叫 |
| `ComposerLogic.swift` | 純邏輯：可用模型、預設選擇、不能產生的原因、是否顯示語氣欄 |
| `Formatting.swift` | 大小、長度、時間的顯示文字 |
| `Waveform.swift` | 把取樣點縮成波形峰值（純函式）＋讀檔 |
| `JobTracker.swift` | 比對前後兩次佇列快照，找出剛完成的工作（純邏輯） |
| `BackendSupervisor.swift` | 啟動／停止內附後端；未打包時改用 `.venv` |
| `Audio.swift` | 播放、錄音 |
| `StudioModel.swift` | 畫面狀態、輪詢、動作 |
| `Theme.swift` | 品牌色、宋體、文字樣式的動作、提示條、列的底色 |
| `*View.swift` | 各區域畫面 |
| `SystemIntegration.swift` | 服務選單、開啟檔案、Dock 圖示 |

## 4. 輪詢

一條背景工作：有進行中的工作或下載時每 0.7 秒查一次 `/api/jobs`、`/api/models`，
閒置時每 3 秒查一次佇列（才看得到 Claude 經 MCP 送來的工作）。
`JobTracker` 發現有工作剛完成就重讀紀錄；是這個 app 自己送出的才自動播放。

## 5. 復原

- 音檔：`NSWorkspace.recycle` 取得垃圾桶裡的位置 → 呼叫刪除 API → 登記復原動作；
  復原時把檔案搬回原位，再呼叫 `/api/history/restore` 把紀錄放回去。
- 聲音：三個檔案（wav、txt、json）一起進垃圾桶；復原時搬回來即可（聲音庫是直接讀資料夾）。

## 6. 系統整合

- **服務選單**：`Info.plist` 宣告 `NSServices`（接受純文字），`NSApp.servicesProvider` 收到後
  把文字放進稿子並切到「產生」。
- **開啟檔案**：宣告可開啟純文字檔；`application(_:open:)` 讀進稿子。
- **Dock**：佇列有工作時顯示數量；app 在背景時完成工作，Dock 圖示跳一下。
- **選單列圖示**：改用引號符號，選單裡顯示服務狀態與進行中的工作數，另有「唸出剪貼簿的文字」。

## 7. 後端打包

`bundle-backend.sh` 改為複製整個 `studio` 套件（不含測試），
`BackendSupervisor` 以 `python3 -m studio.app` 啟動、工作目錄設在 `backend/`。
