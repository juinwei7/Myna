# Spec 002 — 九官鳥：Mac app 介面重構

| | |
|---|---|
| 狀態 | 已完成（2026-11-18） |

---

## 1. 問題

現在的 app 是「網頁版換成原生外殼」：一個視窗、左邊紀錄、右邊稿子。
Spec 001 讓後端支援 8 個模型之後，這個版面裝不下新功能，也還不夠像一個 Mac app：

1. **沒有地方管模型**：下載、刪除、看授權、設預設，全都沒有介面。
2. **聲音庫只能新增**：不能試聽參考錄音、改名、改逐字稿、刪除。
3. **看不到進度、不能取消**：只有一行「產生中… 12 秒」。
4. **比較模型很麻煩**：要自己換模型、按產生、記住哪個是哪個。
5. **刪錯救不回來**：刪除沒有 ⌘Z。
6. **名字和圖示沒有辨識度**：「語音工作室」是功能描述；圖示是綠底白色聲波條，跟很多錄音 app 分不出來。

## 2. 目標

### 命名與圖示

- 產品名稱改為 **九官鳥**（英文 Myna）：會學人講話的鳥，錄十秒就學會你的聲音。
  中間用過「聲坊」，跟別的產品撞名而改掉。
- 圖示：柿橘色圓角方塊上一隻張嘴的九官鳥（黑色的鳥、黃色的喙），嘴邊有聲波。避開綠色與聲波條。
- 內部代號不動：bundle id `local.weiwei.voicestudio`、資料夾 `Application Support/VoiceStudio`、
  連接埠 8790。**為什麼**：改了會丟掉麥克風授權、登入項目，已經接好的 AI 工具也要重設。

### 資訊架構

側欄導覽四個區域（⌘1～⌘4）：

| 區域 | 用途 |
|---|---|
| **產生** | 寫稿子、選聲音與模型、產生、試聽、比較 |
| **音檔** | 所有產生過的音檔：表格、排序、搜尋、多選 |
| **聲音庫** | 仿聲用的參考聲音：試聽、改名、改逐字稿、刪除、新增 |
| **模型** | 目錄：下載、進度、取消、載入／卸載、設為預設、刪除、加入自訂模型 |

### 範圍內

- 「產生」頁：稿子＋下方「這份稿子的版本」＋右側檢閱器（聲音、模型、語氣、語速、比較模型）；方式在工具列中間切換
- 視覺語言：自己的主色（柿橘）、宋體標題、單色側欄、文字樣式的次要動作，內容頁讀起來像一份文件
- 音檔詳情頁：標題、基本資料、同一批比較、稿子全文、實際唸的文字
- 佇列：進行中的工作顯示進度條與階段文字，可取消；Claude 經 MCP 送來的工作也會出現
- 比較：勾選多個模型一次送出，同一批的產出排在一起
- 播放列：波形、點按或拖曳跳轉、試聽倍速
- 刪除可復原（⌘Z）：音檔與聲音都先進垃圾桶
- 系統整合：服務選單（在任何 app 選取文字 →「用九官鳥唸出來」）、把文字檔拖到 Dock 圖示、
  Dock 圖示顯示佇列數量、背景完成時提醒
- 設定：側欄式的視窗（產生、發音字典、模型與記憶體、一般、AI 工具、檢查與狀態），每頁工具列右邊的齒輪可以打開

### 範圍外

- **捷徑（App Intents）**：需要 Xcode 建置流程產生中繼資料，SwiftPM 命令列建置做不出來
- **系統通知**：未經 Developer ID 簽章的 app 通知權限會被系統拒絕，改用 Dock 提醒
- 多視窗、文件模式：稿子很短，一個視窗夠用
- 串流播放

## 3. 約束

### C-1 介面不含業務邏輯（憲法 A1）
哪個模型能配哪個方式、缺什麼不能產生，以 `/api/models` 的能力欄位為準；
畫面端的推導集中在可測試的 `ComposerLogic`，不散在各個 View。

### C-2 遵循 macOS 人機介面準則（憲法 U1～U6）
驗收時逐條對照 `macos-design-guidelines` 的檢查表。

### C-3 沒有模型也要能用
第一次開啟、一個模型都沒有時，「產生」頁要直接引導去下載，不能是一片空白或錯誤訊息。
要下載哪個由使用者自己選：列出推薦的幾個（大小、能力、授權都看得到），不替人決定。

### C-4 未打包也能跑
`swift run` 直接執行時（沒有 bundle、沒有內附後端），改用專案根目錄的 `.venv` 啟動後端；
登入項目這類需要 bundle 的功能靜默停用。

## 4. 使用者故事

1. **第一次打開**：看到推薦的幾個模型，自己挑一個按下載，進度看得到。
2. **寫稿、產生、聽**：⌘↩ 產生，做完自動播放，波形上看得到播到哪。
3. **換模型比較**：打開「比較模型」勾三個，一次產生，三筆排在一起逐一聽。
4. **描述出好聲音就留下來**：在產出上按「存成聲音」，之後用仿聲重現同一個音色。
5. **拿去用**：把音檔直接拖到 Finder、剪輯軟體或聊天視窗。
6. **刪錯了**：⌘Z 救回來。
7. **在別的 app 選一段字**：右鍵 → 服務 →「用九官鳥唸出來」，稿子帶進九官鳥。
8. **Claude 幫我產生**：Claude 經 MCP 送出工作時，九官鳥的佇列看得到進度，做完出現在音檔清單。
